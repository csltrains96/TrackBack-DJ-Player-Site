Changelog

RELEASE NOTES

What's new, what's fixed, and what's changed in TrackBack — newest first.

v1.2 Fixes Latest
  • Fixed a stubborn WebView2 bug where audio elements could fire a spurious "ended" event right after loading a previously-finished track, occasionally causing crossfades into an already-played song
  • Added a triple-guard system around track transitions to catch this class of phantom-end issue going forward
  • Fixed stale idle-slot preloads that could cause a crossfade into the wrong track
  • Added a self-crossfade guard to prevent a track from fading into itself
  • Narrowed overly broad "stuck" playback detection that was triggering false positives
  • Fixed an audible pop at the end of a fade-out
v1.1 Features
  • Added session persistence — your playlist, playback position, and settings now survive lock, sleep, and app close
  • Added an ID3 tag cache with embedded album art, so re-opening a library you've already scanned is near-instant
  • Improved ID3 tag reading for older files using Windows-1252 encoding — em-dashes and curly quotes now display correctly instead of as garbled symbols
v1.0 Launch
  • Initial release of TrackBack
  • Folder-based music library with automatic ID3 tag scanning
  • Dual-element crossfade engine with configurable duration
  • Real-time spectrum analyzer with zone-coloured gradients and peak hold
  • Album art lookup via Discogs and the MusicBrainz Cover Art Archive
  • Lightweight native Windows app, built on Tauri instead of Electron
