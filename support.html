Help

SUPPORT

Stuck on something? Here's how to get TrackBack running smoothly, plus answers to the questions we hear most.

System requirements

  • Windows 10 or Windows 11 (64-bit)
  • A local folder of music files (MP3, FLAC, WAV, and other common formats)
  • Internet connection required only for album art lookup, license activation, and update checks

Common issues

A track cuts out or crossfades early / doesn't crossfade at all

Check your crossfade duration in Settings — a duration longer than the track's remaining playtime can cause early transitions. If playback seems "stuck" on a track that's already finished, try skipping manually once; this is a known WebView2 edge case we've patched repeatedly, so make sure you're on the latest version first.

My license key won't activate

Double-check the key was copied without extra spaces, and confirm you haven't already used all 3 machine activations. If you need to move to a new machine, deactivate an old one first from Settings → License, or email us and we'll deactivate one for you.

Album art won't load

Album art lookup calls out to Discogs and MusicBrainz over the internet — confirm you're online and that a firewall or VPN isn't blocking the request. This feature only runs when you trigger it manually, so nothing happens in the background.

My library, playlists, or session didn't restore after restart

TrackBack saves session state (playlist, position, settings) locally as you use the app. If a session didn't restore, the most common cause is the app being force-closed rather than closed normally. Try reopening the folder manually — your ID3 tag cache will still be intact, so re-scanning should be fast.

Tags or titles show garbled characters

Older MP3s sometimes use Windows-1252 encoding for ID3 tags instead of UTF-8. TrackBack detects and handles this automatically as of recent versions — if you're still seeing garbled em-dashes or curly quotes, make sure you're on the latest release.

Still stuck?

Check the release notes to confirm you're on the latest version — a lot of issues are already fixed there. Otherwise, reach out directly:
